# Web font source

The Chinese typeface is Alibaba PuHuiTi 2.0. Its WOFF2 subsets were downloaded
from the official font service at `fonts.alibabadesign.com` (linked by
`https://www.alibabafonts.com/`). They are self-hosted because the official
service restricts font requests from unrelated domains. The font binaries have
not been modified; `tools/localize-fonts.mjs` records the source and conversion
of URLs in `portfolio-font.css`.

The large Latin display text retains the existing optional local display face.
